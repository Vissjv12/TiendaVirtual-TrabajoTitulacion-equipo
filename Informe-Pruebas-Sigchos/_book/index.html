# Introducción y Alcance de las Pruebas

\begin{infobox}[Sistema Sigchos E-Commerce]
El presente documento consolida de manera cronológica, técnica y verificable todas las pruebas ejecutadas entre el \textbf{07 y el 18 de noviembre de 2026} sobre el \textbf{Sistema de Comercio Electrónico para los Emprendimientos del Cantón Sigchos} (\textit{Feria Digital Sigchos}), tanto en el entorno local de desarrollo como en el servidor de producción institucional (\texttt{https://tienda.gadmsigchos.gob.ec:444}).
\end{infobox}

Este informe abarca pruebas unitarias, pruebas web con \texttt{MockMvc}, pruebas de integración con H2/MySQL/Redis, auditorías de seguridad perimetral en el API Gateway NGINX, mediciones comparativas de rendimiento con \texttt{k6}, ensayos de respaldo y restauración en MySQL 8.4.9, validaciones en navegador Google Chrome y transacciones completas en vivo sobre la pasarela PayPhone Sandbox.
